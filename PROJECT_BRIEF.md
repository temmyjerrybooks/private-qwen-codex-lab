# Project Brief

## Problem

Developers need a private coding agent that can work inside VS Code, understand the current workspace, and assist with real development workflows without becoming a public SaaS product.

## Solution

Borger is a VS Code-first coding agent extension backed by an OpenAI-compatible LiteLLM gateway and a Modal-hosted coding model.

## Target User

The initial target user is a single developer using Borger privately on local projects.

## Product Vision

Borger should become a senior-engineer-style assistant that can inspect code, plan work, propose diffs, apply approved edits, run verification commands, fix errors, and summarize completed work.

## Non-Goals

- Public SaaS
- Public signups or billing
- Browser-first chatbot UI
- Marketplace publishing in the first version
- Automatic destructive workspace operations
